# Production plan template

## Production identity

Production ID/version; objective; audience; platform; aspect ratio; duration; CTA; deliverables; creative director.

## Reference evidence

For each reference, state access status and method. Include a full timestamped scene breakdown with visual, composition, motion/transition, type/copy, audio/beat, and production implication. Label anything inferred from transcript, stills, or description rather than directly observed.

## Fidelity contract

- Must preserve
- Must adapt
- Must exclude
- Measurable tolerances
- Rights/provenance limits

## Production matrix

| Scene | Time | Reuse / extend / invent | Source | Direction | Acceptance criteria |
|---|---|---|---|---|---|

## Storyboard and timing

Describe shots, layers, transitions, hidden swaps, camera moves, typography, easing, duration, and audio/beat cues. Specify outcomes rather than software commands unless a tool is mandated.

## Asset manifest

List each asset, origin, permission/licence status, treatment, and fallback. Never invent rights or availability.

## Acceptance criteria

Use observable criteria: deliverable properties, visual grammar, timing tolerances, legibility, safe areas, sync, continuity, and finish.

## Risks, assumptions, and rejected directions

State what could prevent fidelity, what remains unverified, what the plan assumes, and why alternatives were rejected.

## Approval request

Ask: “Approve Video Production Gate for plan version X” or request named changes. Plan approval authorizes implementation only, not delivery.
